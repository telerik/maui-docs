# .NET MAUI TimePicker Keyboard Navigation Support on Desktop

The [Telerik UI for .NET MAUI TimePicker]({%slug timepicker-overview%}) provides keyboard navigation support on WinUI and MacCatalyst.

The table below lists the available keyboard combinations and their corresponding actions:

| Hotkey | Action |
| ------ | ------ |
| `Tab` | Enters or exits the picker. Also navigates between the different elements - spinners, cancel and ok buttons. |
| `Left Arrow` | Navigates to the previous spinner. |
| `Right Arrow` | Navigates to the next spinner. |
| `Up Arrow` | Highlights the previous time value. |
| `Down Arrow` | Highlights the next time value. |
| `Enter` | Opens the drop-down. When the drop-down is open, selects the currently highlighted time. |
| `Space` | Opens the drop-down. |
| `Esc` | Closes the drop-down. |
