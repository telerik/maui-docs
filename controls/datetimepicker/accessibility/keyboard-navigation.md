# .NET MAUI DateTimePicker Keyboard Navigation Support on Desktop

The [Telerik UI for .NET MAUI DateTimePicker]({%slug datetimepicker-overview%}) provides keyboard navigation support on WinUI and MacCatalyst.

The table below lists the available keyboard combinations and their corresponding actions:

| Hotkey | Action |
| ------ | ------ |
| `Tab` | Enters or exits the picker. Also navigates between the different elements - spinners, cancel and ok buttons and date and time part. |
| `Left Arrow` | Navigates to the previous spinner. |
| `Right Arrow` | Navigates to the next spinner. |
| `Up Arrow` | Highlights the previous date or time value. |
| `Down Arrow` | Highlights the next date or time value. |
| `Enter` | Opens the drop-down when the focus is over the picker. When the drop-down is opened, selects the currently highlighted date and time. |
| `Space` | Opens the drop-down. |
| `Esc` | Closes the drop-down. |
