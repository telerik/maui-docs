# .NET MAUI Rating Visual States

This article describes the visual states provided by the Rating control. You can use these visual states to change the appearance of the control based on its state&mdash;such as when it’s disabled, hovered, and more.

The Rating provides the following `CommonStates` visual states:

| Visual State | Description |
| ------------- | --------------- |
| `Normal` | Applies when the Rating is in its normal state. |
| `MouseOver` | (Desktop-only) Applied when the mouse cursor is hovering over the Rating. |
| `Disabled` | Applied when the Rating `IsEnabled` is `False`. |
