# .NET MAUI Rating Keyboard Navigation Support on Desktop

The [Telerik UI for .NET MAUI Rating]({%slug rating-overview%}) provides keyboard navigation support on WinUI and MacCatalyst.

The table below lists the available keyboard combinations and their corresponding actions:

| Hotkey | Action |
| ------ | ------ |
| `Tab` | Enters or exits the rating control. |
| `Shift + Tab` | Rating receives focus. |
| `Right Arrow` | Navigates to the next item in the rating control and selects it. |
| `Left Arrow` | Highlights the previous item in the rating control and deselects it. |
