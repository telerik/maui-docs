# .NET MAUI ListPicker Keyboard Navigation Support on Desktop

The [Telerik UI for .NET MAUI ListPicker]({%slug listpicker-overview%}) provides keyboard navigation support on WinUI and MacCatalyst.

The table below lists the available keyboard combinations and their corresponding actions:

| Hotkey | Action |
| ------ | ------ |
| `Tab` | Enters or exits the picker. Also navigates between the different elements - spinner, cancel and ok buttons. |
| `Up Arrow` | Highlights the previous item. |
| `Down Arrow` | Highlights the next item. |
| `Enter` | Opens the drop-down when the focus is over the picker. When the drop-down is open, selects the currently highlighted item. |
| `Space` | Opens the drop-down. |
| `Esc` | Closes the drop-down. |
