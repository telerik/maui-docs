# .NET MAUI CheckBox Keyboard Navigation Support on Desktop

The [Telerik UI for .NET MAUI CheckBox]({%slug checkbox-overview %}) provides keyboard navigation support on `WinUI` and `MacCatalyst`.

| Hotkey | Action |
| ------ | ------ |
| `Space` | Changes the checkbox state&mdash;indeterminate, checked, unchecked. |
