# .NET MAUI Carousel Keyboard Navigation Support on Desktop

The [Telerik UI for .NET MAUI Carousel]({%slug carousel-overview%}) provides keyboard navigation support on WinUI and MacCatalyst.

The table below lists the available keyboard combinations and their corresponding actions:

| Hotkey | Action |
| ------ | ------ |
| `Tab` | Enters or exits the carousel control. |
| `Shift + Tab` | Carousel receives focus. |
| `Right Arrow` | Navigates to the next item in the carousel control. Horizontal orientation only. |
| `Left Arrow` | Navigates to the previous item in the carousel control. Horizontal orientation only. |
| `Up Arrow` | Navigates to the previous item in the carousel control. Vertical orientation only. |
| `Down Arrow` | Navigates to the next item in the carousel control. Vertical orientation only. |
| `Home` | Navigates to the first item in the carousel control. |
| `End` | Navigates to the last item in the carousel control. |

>tip Tapping or clicking an item also focuses the Carousel, which enables keyboard navigation through the items.
