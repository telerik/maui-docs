# .NET MAUI NumericInput Keyboard Navigation Support on Desktop

The [Telerik UI for .NET MAUI NumericInput]({%slug numericinput-overview %}) provides keyboard navigation support on `WinUI` and `MacCatalyst`.

| Hotkey | Action |
| ------ | ------ |
| `Tab` | Enters or exits the NumericInput. |
| `Up Arrow` | Changes the input value to upper value. |
| `Down Arrow` | Changes the input value to lower value. |
