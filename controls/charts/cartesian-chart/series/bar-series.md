# .NET MAUI Cartesian Chart Bar Series

The `BarSeries` represents each data point as a bar. It requires a `CategoricalAxis` and a `NumericalAxis`.

## Features

The Bar Series binds to data through the [common series properties]({% slug charts-cartesian-series %}) (`ItemsSource`, `HorizontalBinding`, and `VerticalBinding`) and renders each data item as a bar.
