# Video Onboarding

Telerik UI for .NET MAUI offers a comprehensive [video training course](https://www.youtube.com/playlist?list=PLvmaC-XMqeBb8aH4rJbqRUl42cSriduua) available to all developers. This class is designed to help you get started with the Telerik UI for .NET MAUI components and features. It aims to put you in the shoes of an engineer who adds new features to an existing application.

The learning process starts by adding basic UI components to the application and shows how to harness the power of the Telerik UI for .NET MAUI controls and features in no time. Further on, you'll get into more advanced components, like the Chart, DataGrid, and DataForm. Then, you will learn how to incorporate Telerik UI components to interact with existing functionality and with each other. Finally, the course will explore the styling options provided by the Telerik UI for .NET MAUI controls.

## Course Chapters

The Telerik UI for .NET MAUI technical online training has an approximate duration of 2 hours and is split into seven modules with the following learning path:

Use the written topic links under each chapter to learn without playing the videos. 

* **Chapter 1: Welcome** (Introduction, About Telerik UI for .NET MAUI, Course Prerequisites, Course Resources)
  * Written topic path: [System requirements]({%slug system-requirements%}) and [sample applications and learning resources]({%slug sampleapps-overview%}).
* **Chapter 2: Getting Started** (Overview, Installation, Project Code, First Control, Running the Demos)
  * Written topic path: [Set up Telerik UI for .NET MAUI and create a project]({%slug maui-quick-start%}), [add your first Button]({%slug button-getting-started%}), and [run the SDKBrowser examples]({%slug sdkbrowser-app%}).
* **Chapter 3: Basic UI Components** (Overview of the Basic UI Controls, Inputs, ListPicker, TabView)
  * Written topic path: [Add an Entry for text input]({%slug entry-getting-started%}), [add a NumericInput]({%slug numericinput-getting-started%}), [add a ListPicker]({%slug listpicker-getting-started%}), and [add a TabView]({%slug tabview-getting-started%}).
* **Chapter 4: DataGrid** (DataGrid Overview, Setup, Columns, Column Templates, Sorting, Filtering, Selection)
  * Written topic path: [DataGrid setup]({%slug datagrid-getting-started%}), [defining DataGrid columns]({%slug datagrid-columns-overview%}), [DataGrid template columns]({%slug datagrid-columns-template-column%}), [DataGrid sorting]({%slug datagrid-sorting-overview%}), [DataGrid filtering]({%slug datagrid-filtering-overview%}), and [DataGrid selection]({%slug datagrid-selection-overview%}).
* **Chapter 5: Chart** (Chart Overview, Anatomy, Chart Setup, Categories and Series, Labels)
  * Written topic path: [Chart anatomy]({%slug chart-visual-structure%}), [Chart setup]({%slug chart-getting-started%}), [Chart series types]({%slug chart-series-overview%}), and [Chart series labels and category binding]({%slug chart-series-features%}).
* **Chapter 6: DataForm** (DataForm Overview, Setup, Editors, Commit Modes)
  * Written topic path: [DataForm setup]({%slug dataform-getting-started%}), [DataForm built-in editors]({%slug dataform-editors%}), and [DataForm commit modes]({%slug dataform-commit-data%}).
* **Chapter 7: Styling** (Styling Overview, Examples, Palette Styling, Resources)
  * Written topic path: [Button styling examples]({%slug button-styling%}), [theming overview]({%slug themes-overview%}), [customizing theme colors]({%slug themes-customization%}), and [customizing control-specific theme resources]({%slug theme-component-styles-customization%}).

To learn more and continue with the video onboarding process, [follow the complete Telerik UI for .NET MAUI chapter playlist](https://www.youtube.com/playlist?list=PLvmaC-XMqeBb8aH4rJbqRUl42cSriduua).
