# Breaking Changes in Version 16.0.0

This article lists the breaking changes introduced with the Telerik UI for .NET MAUI 16.0.0 release version.

## Charts

The [Charts]({% slug charts-overview %}) introduce `CartesianValueSeries` as the base class for `AreaSeries`, `BarSeries`, `LineSeries`, and `PointSeries`. It inherits from `CartesianSeries`, so you can still use these series as `CartesianSeries`.

The following properties move to more specific series classes:

| Property | Old Class | New Class |
| -------- | --------- | --------- |
| `VerticalBinding`, `LabelOffset` | `CartesianSeries` | `CartesianValueSeries` |
| `ShowLabels`, `LabelStyle`, `Stroke` | `ChartSeries` | `CartesianValueSeries` and `PieSeries` |
| `StrokeThickness` | `ChartSeries` | `CartesianValueSeries`, `PieSeries`, and `FinancialSeries` |

If your code accesses these properties through `ChartSeries` or `CartesianSeries`, use the appropriate class from the table instead. Update styles targeting the old base classes in the same way. `DonutSeries` inherits the properties from `PieSeries`.

The corresponding bindable property fields also move. For example, replace `CartesianSeries.VerticalBindingProperty` with `CartesianValueSeries.VerticalBindingProperty`, and `ChartSeries.ShowLabelsProperty` with the field on `CartesianValueSeries` or `PieSeries`.

Financial series do not support labels. Use `BullishStroke` and `BearishStroke` instead of `Stroke`; set both to the same brush for a common stroke.

> Existing property assignments on supported concrete series, such as `LineSeries.ShowLabels` and `BarSeries.VerticalBinding`, remain available. These changes do not affect the compatibility charts.

## DataGrid

The [DataGrid Grouping Panel]({% slug datagrid-grouping-ui %}) now uses the Telerik UI for .NET MAUI [`RadCollectionView`]({% slug collectionview-overview %}) to list the group items. Before, the .NET MAUI `CollectionView` was used.
